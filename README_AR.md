# Pseudo practical — دليل سريع (لغير المبرمج)

## 1) الرفع على GitHub
1. أنشئ حسابًا على github.com ثم زر **New repository** (اسم مثل `pseudo-practical`، اختر Public).
2. اضغط **uploading an existing file** وارفع محتويات المجلد: `index.html` و`data.json` و`favicon.png` و`.nojekyll` ومجلد `images`.
   - **تنبيه:** GitHub يقبل حتى **100 ملف في الرفعة الواحدة**. عندك ~57 ملفًا في `images` + 4 ملفات، فيكفي رفعة واحدة؛ إن أضفت صورًا كثيرة ارفعها على دفعات (اضغط Commit بعد كل دفعة).
   - مجلد `scripts` و`review.json` و`report.json` اختياريان (للمطوّر)؛ لا يؤثران على الموقع.
3. اضغط **Commit changes**.

## 2) تفعيل الموقع
Settings → Pages → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save. انتظر دقيقة.

## 3) الرابط والمشاركة
الشكل: `https://اسم-حسابك.github.io/pseudo-practical/` — شاركه كما هو، يعمل على الموبايل والكمبيوتر.

## 4) التعديل
- **تعديل مصطلح:** افتح `data.json` في GitHub ← أيقونة القلم ← ابحث عن `"name": "..."` وعدّل النص فقط ← Commit.
  - المرادفات المقبولة في الكتابة تُضاف في `"alt": ["..."]`.
- **إضافة صورة لمجسم موجود:** ارفع الصورة في `images/` (اسم lowercase بلا مسافات، webp) ثم أضف في `pages` الخاص بالمجسم عنصرًا `{"img":"images/اسم.webp","pins":[...],"masks":[]}`.
  - كل `pin`: `{"n":1,"name":"...","alt":[],"x":..,"y":..,"w":..,"h":..}` والقيم نسب % من الصورة (x,y الزاوية العلوية اليسرى).
- **إضافة مجسم جديد:** أضف عنصرًا جديدًا في أعلى مستوى: `{"id":"اسم","en":"...","ar":"...","pages":[...]}`. قسم الـ X-ray موجود فارغًا (`id: xray`) فقط املأ `pages`.
- أي تعديل ينعكس على الموقع بعد دقيقة من الـ Commit.
